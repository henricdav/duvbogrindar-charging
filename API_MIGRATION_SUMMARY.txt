╔═══════════════════════════════════════════════════════════════════════════╗
║                        NEW API SPECIFICATION                               ║
╚═══════════════════════════════════════════════════════════════════════════╝

Endpoint Format:
  GET https://www.elprisetjustnu.se/api/v1/prices/[ÅR]/[MÅNAD]-[DAG]_[PRISKLASS].json

Parameters:
  ÅR         4-digit year          Example: 2024
  MÅNAD      2-digit month         Example: 01, 02, ..., 12
  DAG        2-digit day           Example: 01, 02, ..., 31
  PRISKLASS  Price area           SE3 (Stockholm/Södra Mellansverige)

Example:
  https://www.elprisetjustnu.se/api/v1/prices/2024/01-15_SE3.json

Response Format:
  [
    {
      "time_start": "2024-01-15T00:00:00+01:00",
      "time_end": "2024-01-15T01:00:00+01:00",
      "SEK_per_kWh": 0.85,
      "EUR_per_kWh": 0.08
    },
    ... 24 hourly entries
  ]

╔═══════════════════════════════════════════════════════════════════════════╗
║                            DATA FLOW                                       ║
╚═══════════════════════════════════════════════════════════════════════════╝

1. Cron Job (Daily at 2 AM) or Manual Trigger
   └─▶ Calls fetchAndStorePrices()

2. Fetch Today's Prices
   └─▶ GET /api/v1/prices/2024/01-15_SE3.json
   └─▶ Parse JSON array
   └─▶ Extract time_start and SEK_per_kWh

3. Fetch Tomorrow's Prices (if available)
   └─▶ GET /api/v1/prices/2024/01-16_SE3.json
   └─▶ 404 OK if not yet available (before 13:00)

4. Store in Database
   └─▶ INSERT INTO spotprices (ts, price_sek_per_kwh)
   └─▶ ON CONFLICT DO UPDATE

5. Log Results
   └─▶ "Stored X price records"
